CYBERSECURITY & NETWORK SECURITY CURRICULUM

مسار الدروس والدراسة المنهجية

دروس ومناهج شاملة في أمن السيارات، وأمن الشبكات (Network Security)، بدعم ثنائي اللغات (عربي / إنجليزي).

الدرس الأول: المفاهيم الأساسية والأمن السيبراني للمركبات

1. ناقلات الهجوم ونقاط الدخول

الطرق والمسارات المستغلة للوصول لوحدات التحكم (ECUs) مثل الواي فاي، منافذ OBD2، والثغرات البرمجية.

2. التهديدات والنتائج

تتراوح بين سرقة البيانات والسيطرة على الأنظمة الحرجة، مما يمس السلامة العامة.

3. نظام إدارة الأمن (CSMS)

إطار لضمان دمج تدابير الأمان طوال دورة حياة المركبة والامتثال للمعايير الدولية.

4. استراتيجيات الدفاع

عزل الأنظمة الحيوية، التشفير والمصادقة، وأنظمة كشف التسلل (IDS).

Lesson 1: Core Concepts & Automotive Cybersecurity

1. Attack Vectors & Entry Points

Paths like wireless access, physical OBD2 ports, and software flaws to reach vehicle ECUs.

2. Threats & Consequences

Ranging from privacy breaches to critical operational control loss impacting safety.

3. CSMS Framework

Lifecycle governance ensuring threat mitigation and global standard compliance.

4. Defense Approaches

System isolation, payload encryption/authentication, and intrusion detection systems (IDS).

مسار أمن الشبكات وحماية البنية التحتية (Network Security)

تصفح مجلد network-security

1. مراقبة وتقسيم الشبكات (Network Segmentation)

تطبيق جدران الحماية (Firewalls) وقوائم التحكم بالوصول (ACLs) لتجزئة الشبكة ومنع انتشار التهديدات بين القطاعات.

2. تحليل الحزم واكتشاف الشذوذ (Packet Inspection)

استخدام أدوات مثل Wireshark و Scapy لفحص حركة المرور الحيّة واكتشاف حزم البيانات غير المصرح بها.

3. كشف وحماية النطاق (IDS / IPS Hardening)

تجهيز أنظمة كشف ومنع التسلل لمراقبة المنافذ والبروتوكولات (OpenSSH, Apache, DNS) والتصدي لمخاطر الاختراق.

4. تأمين بروتوكولات التشفير والتحقق

تطبيق تشفير قنوات النقل (TLS/SSL) وآليات المصادقة القوية لمنع هجمات التسمم والتجسس (MITM Attacks).

Network Security & Infrastructure Defense Module

Open network-security Directory

1. Network Segmentation & Access Control

Implementing Firewalls and Access Control Lists (ACLs) to isolate critical subnets and prevent lateral movement.

2. Deep Packet Inspection & Anomaly Detection

Utilizing Wireshark and Scapy for live traffic capturing, payload analysis, and anomaly identification.

3. IDS/IPS Deployment & Hardening

Configuring Intrusion Detection/Prevention systems to safeguard key services (SSH, Web, DNS) against exploitation.

4. Encryption & Secure Authentication

Enforcing TLS/SSL transport security and robust authentication protocols to prevent Man-in-the-Middle (MITM) attacks.
