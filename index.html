كيف يحول نظام Markdown موقعك الهادئ إلى مدونة ومكتبة ديناميكية؟

بدلاً من تعديل أكواد HTML وإنشاء ملف جديد يدوياً لكل مقال، يمكنك تنظيم المجلدات في حسابك على GitHub وكتابة منشوراتك بصيغة .md. ستقوم خدمات GitHub تلقائياً (عبر Jekyll المدمج أو كود JavaScript بسيط) بتحويل هذه الملفات إلى صفحات ويب أنيقة!

1

هيكلة المجلدات في GitHub

أنشئ مجلدات مخصصة داخل المستودع الخاص بك لتقسيم المحتوى بسهولة:

📁 mohamed.cyber/
├── 📁 lessons/
└── 📄 acl-guide.md
├── 📁 news/
└── 📄 cve-2026.md
├── 📁 articles/
└── 📄 index.html
2

إضافة ترويسة Front Matter

في بداية كل ملف .md، أضف ترويسة بسيطة بتنسيق YAML لتعريف العنوان، التاريخ، والكاتب: 

---
title: "تأمين الراوتر عبر ACL"
date: 2026-10-28
category: lessons
author: Mohamed Yacine
---
3

الربط التلقائي والتشغيل

يمكنك استخدام Jekyll (المدمج مجاناً في GitHub Pages) أو استخدام مكتبة Marked.js لقراءة ملفات الـ Markdown مباشرة وعرضها داخل موقعك تلقائياً دون الحاجة لإعادة رفع الموقع!

كيف تعرض ملفات الـ Markdown تلقائياً في موقعك الحالي بـ JavaScript؟

ضع هذا الكود البسيط في موقعك الحالي وقدم اسم الملف عبر الرابط (مثلاً: site.com/?lesson=acl-guide)، وسيقوم الموقع بجلب الدرس وتحويله تلقائياً لقالب سيبراني أنيق: 

// Fetch and render markdown automatically
async function loadCyberPost(category, fileName) {
    try {
        const response = await fetch(`/${category}/${fileName}.md`);
        const markdownText = await response.text();
